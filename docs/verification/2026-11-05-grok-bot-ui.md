# Mira Android 界面重构

视觉对照使用 [Grok Bot 官方 Google Play 截图](https://play.google.com/store/apps/details?id=ai.x.grok.bot) 和 [xAI 移动端说明](https://docs.x.ai/grok-bot/mobile)。独立的 Grok Bot 客户端提供了头像入口、收件箱、对话气泡、附件入口与底部操作面板的参考。Mira 仍保留自己的头像、产品名称和功能。启动与输入参考 [Shape of AI Suggestions](https://www.shapeof.ai/patterns/suggestions) 和 [Modes](https://www.shapeof.ai/patterns/modes)，共用控件参考 [Astryx 的组合方式](https://astryx.atmeta.com/docs/authoring) 和本地 UI 规范。

| 界面       | 结构变化                                                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Agent      | 头像入口下直接进入收件箱，待跟进和已处理分栏；查漏和本次笔记授权相邻。事项和委托的保存操作平时固定在底部，键盘展开时进入可滚动的表单。独立运行服务通过委托页的状态行打开。 |
| 对话       | 紧凑的联系人式抬头、左右消息气泡和独立附件键。历史搜索和会话操作各有入口，授权与审批通过对应的面板呈现。                                                                   |
| 学习       | 当日进度总览、继续学习区和最近资料分层。继续学习入口含资料名、媒体类型、完成度和操作；空状态可直接导入。                                                                   |
| 笔记与编辑 | 笔记标题和计数移到文档区；头像式单列文档条目支持独立操作菜单。编辑器顶部呈现笔记身份与操作，辅助功能集中到菜单和底部面板。                                                 |
| 设置       | 首页用四个分类承接编辑器、交互、安全、AI；各类控件进入相应底部面板。                                                                                                       |

同一台 Android 35 模拟器共留存旧版 50 张、新版 59 张截图。旧版补拍使用改动前保存的 Android JS bundle；对话和提案样例由本地测试数据生成，没有连接生产模型。系统目录授权与开源许可等原生页面由 Android 渲染。

验证通过：Android bundle 导出、TypeScript、ESLint、Prettier、`git diff --check`，以及 Vitest 的 138 个测试文件和 790 项测试。Android 模拟器通过 Maestro 的历史搜索回归：弹出键盘，输入无匹配标题，验证结果提示可见，键盘打开时关闭历史，返回对话。另在模拟器核对设置修改与恢复、委托服务面板、学习入口、笔记打开和本地提案审阅。

事项表单也通过了 Maestro 回归：在临时工作区打开键盘并输入事项，直接点保存，验证新事项出现在收件箱。
