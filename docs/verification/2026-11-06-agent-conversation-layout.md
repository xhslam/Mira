# Agent 首页：会话列表与对话

以用户提供的第二张截图为布局参考。窄屏先显示会话列表，点一行进入对话，返回后保留会话选中状态。宽屏将列表与当前对话并排放置：左边是搜索、新建、带末条消息预览的会话和工作区入口；右边是居中的会话头像与标题、橙色发送气泡、浅灰回复气泡和胶囊输入框。首屏直接读取当前工作区的历史会话。末条消息预览来自同一个 SQLite 查询，保留工作区过滤与长度上限，不改现有数据库结构。

事项、查漏与委托移到「＋ → 事项与委托」。工作区和四格菜单保留其他页面的入口。对话附件、模型配置、提案审阅与停止生成仍可使用。

Android 35 模拟器使用本地会话样例，验证手机竖屏的会话列表与对话，以及宽屏并排显示和切换会话。样例未连接在线模型。快照使用实际模拟器输出。
