# Android 系统返回离开应用

真机用户报告在应用内左滑触发系统返回后回到桌面。源码显示学习子页和笔记编辑器的页面状态由 React 管理，但未接管系统返回，外壳也没有导航历史兜底。未被消费的返回交给 Android，由系统处理 Activity。

系统返回优先关闭当前弹层或由可见子页处理。学习复用页面返回按钮的行为，包括 Craft 的草稿确认和英语陪练的暂停保存。笔记编辑器使用既有的保存与恢复保护。外壳在主页面之间按访问历史返回，回到起点后保持当前页面。

回归检查位于 `tests/unit/app/app-shell-state.test.ts` 和 `.maestro/09-android-back.yaml`。设备验收需在已启用手势导航的设备上，从右侧边缘分别滑回学习首页、笔记列表和 Agent 首页，并确认保留在应用内。
