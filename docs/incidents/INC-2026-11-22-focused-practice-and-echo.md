# INC-2026-11-22：逐句背诵的控件位移与跟读误播放

## 证据与影响

用户提供 Android 截图并报告：切换长短句时播放/切句按钮上下移动；点击“跟读”后发生非预期播放；录音与辅助信息占据阅读首屏。本次通过代码定位和自动化回归复现相关状态与结构约束，尚未在设备上复现或验证麦克风行为。

## 根因

- 当前句与播放按钮共用自然内容流，控件纵向位置取决于正文换行高度。
- `handleEchoAction` 将同一入口分派到原音试听、开始录音、停止录音和录音回放，入口语义随历史状态变化。
- 录音结果、列表和工具缺少渐进披露；整页会自动跟随当前字幕滚动，和以当前句为中心的阅读模式冲突。
- 切句器直接将单个换行作为边界，OCR/复制文本的软换行可能切出不完整句子。

## 修复与不变量

- 文本/音频练习的页头按实际可用视口定高，句子与译文在受限正文区域滚动，播放/切句控件位于独立下部区域。保留列表虚拟化，不把整个列表再嵌入普通滚动容器。选择下方列表中的句子返回专注区，不自动把专注区滚出视口。
- 练习页仅保留必要返回与句数，不显示大标题和全局切页浮钮。录音默认收起，视觉图标较小但保留 48dp 触控目标；展开后滚到录音区域。
- 跟读只在开始/结束录音之间切换，原音播放与录音回放各自使用独立入口。开始录音前暂停其他音源，异步准备和停止串行化，防止连点重复启动；录音/准备期间不切句，停止后恢复非录音音频模式。退出时清理计时器和原生录音/回放。
- 合并段内软换行后再按句末切分，保留常见缩写与小数保护。新导入使用新规则，不静默重切已有资料、改写字幕时间戳或错配旧译文。
- 句子分析 v3 增加可选语法角色片段，支持主语、谓语、宾语、定语、后置定语、状语、表语与补语。只有合法角色、数量和长度受限、拼接后逐字匹配原文的标注才用于上色。无法确认的部分保持普通文字。旧分析兼容，用户点击句子分析时可补齐配色；不在后台自动请求模型。新增字段沿现有 SQLite JSON payload 往返，无须破坏性迁移。

## 回归证据

- `focused-practice-regression`：阅读区/控件结构、默认折叠、触控区、录音入口与隐式播放分离。
- `analysis-and-echo`：直接录音、独立历史录音回放、非法角色/原文不匹配拒绝、不可变片段。
- `enjoy-player-domain`：段内软换行合并，保留现有英文/中文句末、缩写与小数用例。
- `legacy-snapshot-migration`：新增语法角色 payload 与原始备份保留。

## 尚待设备验收

1. 在窄屏、大字体和横竖屏下交替显示短句、长句，确认按钮位置一致且长句可完整滚动阅读。
2. 展开/收起录音，确认点击跟读直接录音、不播放；保存后再次点跟读开启新录音，只有“回放我的录音”播放录音。
3. 原音单句循环和录音互斥；快速连点、拒绝权限、系统中断、返回页面均不残留后台录音或自动播放。
4. 使用已配置模型生成语法分析，重新打开资料确认配色恢复，旧译文和字幕时间轴保持不变。

本次不包含 APK 构建、覆盖安装、真机麦克风或渲染验收。
