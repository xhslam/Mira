# 笔记重命名遇到目录写入失败

2026-11-06 在内存 VaultStorage 中模拟 `catalog.json` 写入被拒绝。修改前，正文已移动到新路径，旧目录索引仍指向原路径。重命名返回 `IO_FAILURE`，随后使用新仓库实例读取旧名也返回 `IO_FAILURE`。这是受控故障注入。

现在仓库在发布新目录项之前读回正文并校验内容哈希。失败时重读目录索引。索引仍保留旧路径时移回正文；索引已经指向新路径时从新路径读回结果。正常重命名保留文档 ID。此回归覆盖存储拒绝索引写入并保持旧索引可读的情况。Expo 存储仍报告非原子替换。

[回归测试](../../tests/unit/workspace/private-vault-repository.test.ts) 注入失败，验证重开仓库后旧路径和正文仍可读取，清除故障后可用原文档 ID 重试。
