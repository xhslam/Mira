# 学习体验重构：媒体优先，而非 AI 优先

本次重构不复制参考产品的品牌、图标或界面资产，而是吸收其学习顺序：先有正在听的内容，再有同步字幕，然后自然发生点词、收集短语、复听和复习。AI 只在用户主动需要翻译、语境释义或语法解释时出现，不再充当页面的主叙事。

| 底部目的地 | 用户在这里完成的事     | 首屏内容                     | 主要去向             |
| ---------- | ---------------------- | ---------------------------- | -------------------- |
| 发现       | 选择下一段想听的内容   | 最近学习、来源筛选和导入入口 | 打开语料或导入       |
| 学习       | 专注听懂当前句子       | 媒体、同步字幕和播放控制     | 沉浸听力、点词、收藏 |
| 语料       | 管理来源与已收藏内容   | 最近语料、筛选和轻量添加按钮 | 打开对应学习会话     |
| 记忆       | 完成间隔复习           | 今日待复习、闪卡和简洁统计   | 上下文、原媒体定位   |
| 我的       | 管理学习偏好与服务能力 | 进度、播放与转写设置         | 具体设置项           |

## 视觉方向

整体采用深墨色背景、低对比暖灰层级和一枚苔藓绿强调色；大面积内容保持平整，只有播放器、底部浮层和词典使用不同的材质层级。英文句子采用衬线阅读字体，中文说明和控制标签使用系统无衬线字体。屏幕不再使用大量空泛的功能卡、编号入口或解释 AI 的宣传文案；文字、时间和播放状态取代装饰，留白只服务于正在读的一句。

> 设计标准是“正在听什么、现在是哪一句、下一步可以做什么”在任何时刻都一眼可见。

## 关键交互契约

学习页的中心是一条可恢复的媒体会话。小型视频或音频封面位于上方；当前英文字幕位于视觉焦点，译文默认收起；控制条始终保留播放、单句循环、前后跳句、字幕显示和倍速。用户点词会从该词的位置浮出半屏词典，长按连续单词进入选词状态并保存短语。收藏句子、翻译、短语高亮和语法解释都属于当前句的工具，不离开播放上下文。

沉浸听力模式只保留当前句、播放进度、重复、显隐字幕和退出；隐去字幕后不自动暴露正在播放的句子。回到记忆时，闪卡必须携带原句和来源，且可一键回到原媒体时间点。所有底部浮层从触发控件的方向出现，轻按立即反馈；不使用吸引注意的循环动效或夸张弹跳。

## 本次实现边界

现有的本地媒体、字幕、翻译、点词、短语和间隔复习数据均继续保留。发现页仅展示本地可用的最近内容和真实导入入口，不伪造 YouTube/B 站频道或订阅数据。外部内容解析、账号订阅和云同步继续作为后续有正式服务接入条件时的能力；本次先把内容进入应用后的学习体验做完整。
