# Enjoy Player 学习模块整合范围

本次改造在现有 Inkstone/Mira Expo 应用的“学习”页基础上实施。学习数据保留在设备本地 SQLite；不增加登录、账号资料、云端同步、订阅、积分、购买、支付、会员等级或任何付费功能。

## 功能映射与去重策略

| Enjoy Player 能力  | Mira 现有基础               | 本次交付方式                                                                   |
| ------------------ | --------------------------- | ------------------------------------------------------------------------------ |
| 本地媒体与字幕学习 | 已有资源/句子模型与音频练习 | 增加媒体库、SRT/VTT 解析、手动字幕、播放器工作台                               |
| 交互式字幕         | 已有句子选择                | 按时间高亮、点按跳转、词级点按与循环片段                                       |
| Echo 跟读          | 已有音频播放与录音          | 增加 A/B 循环、自动回退、重放回合、跟读队列                                    |
| 发音评估           | 已有录音保存                | 增加本地可解释评分、逐词反馈、录音回放与评测历史；可选用户自配 STT/AI 增强     |
| 音高曲线           | 无                          | 增加录音节奏/音高可视化与原句对比视图                                          |
| 字典、上下文翻译   | 部分 AI 提供方设施已存在    | 增加点词查询、收藏、逐句翻译；有配置时调用用户自配 AI，无配置时可手动保存      |
| SRS 词汇本         | 无                          | 增加本地词库、三档掌握度、SM-2 排程、沉浸式闪卡、Anki CSV 导出                 |
| AI 转写            | 已有生成/AI Provider 基础   | 增加可启动的转写任务、长媒体任务状态和手动校对字幕导入路径                     |
| 哔哩哔哩内容引用   | 无                          | 增加公开 BV/EP 链接引用和本地 SRT/VTT 字幕导入工作流；不绕过平台广告或访问控制 |
| AI 自动翻译        | 无                          | 增加逐句翻译队列、缓存与源文本指纹失效策略                                     |
| 练习海报           | 无                          | 增加本地 SVG 练习海报生成与系统分享                                            |
| Craft 语音表达     | 已有生成与 TTS 基础         | 增加说话/转写/改写/TTS 的本地工作流入口与结果保存                              |
| 课程与日目标       | 已有课程、练习数据          | 扩展本地目标、进度和复习建议；不创建社区或社交账号                             |
| 跨设备同步         | 排除                        | 不实现；所有学习数据只保存在本机                                               |
| 订阅、积分、购买   | 排除                        | 不实现；不显示任何付费墙或等级入口                                             |

## 功能边界

涉及外部 AI、TTS、STT 或翻译服务的请求仅使用用户在现有设置中自行配置的兼容服务与安全保存的密钥。未配置时，应用保持可用，提供本地字幕、录音、词汇、复习和手动输入流程，并给出明确的配置提示。媒体使用用户选取的本地文件或显式粘贴的公开 URL；不实现广告规避、绕过 DRM、绕过访问控制或后台抓取。
